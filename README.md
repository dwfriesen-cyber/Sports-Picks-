# NFL V3 Reconstruction shadow records

Separate experimental weekly confidence pools. Original NFL V1 winners are preserved. This branch does not alter official picks-data or the NHL pipeline. All forecasts and inputs are append-only; latest.json is the replaceable status report.

Ranks freeze only before the first kickoff of a complete eligible NFL week. Already-started or incomplete weeks are blocked. Historical benchmark replication does not establish exact restoration of original V3.
